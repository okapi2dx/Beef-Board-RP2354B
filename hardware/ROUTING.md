# RP2354B 配線整理

2026-09-25 時点の保守的な配線整理です。基板外形、81 個の部品位置、ビア位置、ネット、線幅、層は維持しました。細かな階段状配線を元経路から最大 0.03 mm の中心線差でまとめ、銅箔ゾーンを再計算しました。J1・J4 の USB コネクタの GND パッドと J32 の GND パッドは、サーマルスポーク不足を解消するためゾーンへ直接接続しました。

| 項目 | 整理前 | 整理後 |
|---|---:|---:|
| 配線線分 | 2,480 | 1,257 |
| 配線長合計 | 2,036.02 mm | 2,029.71 mm |
| ビア | 116 | 116 |
| 未配線 | 0 | 0 |
| KiCad DRC 指摘 | 56 | 47 |

残る DRC 指摘の内訳は、フットプリントライブラリの差異 27、シルク関連 12、コートヤード重複 7、穴の重複 1 です。基板製造の前に個別確認が必要です。

次の改善候補は電源系の長い配線とビア数の削減です。これは部品位置や配線層の見直しを伴うため、電源経路、信号品質、実装余裕を確認しながら進めます。
