# Beef Board RP2354B 配線効率化版

ユーザー指定の R ドライブ上の PCB を基準に、20 区間の信号配線を短縮しました。元ファイルへの上書きは行っていません。KiCad 10 で同梱のプロジェクトを開いてください。

| 項目 | 入力ファイル | 整理後 |
|---|---:|---:|
| 配線長 | 2037.95 mm | 2030.71 mm |
| 線分数 | 1225 | 1103 |
| ビア | 115 | 115 |
| 未配線 | 0 | 0 |
| DRC 指摘 | 46 | 45 |

短縮量は約 7.24 mm（約 0.36%）です。エンコーダ、ボタン入力、LED 制御などの経路を整理しました。線幅とネット、層の構成は維持し、銅箔ゾーンを再計算しています。USB と電源配線の経路は変更していません。J1 と J4 のライブラリ参照を `BEEF-BOARD:USB-C-TH_G-SWITCH_GT-USB-7038X_1` に合わせました。パッド形状・番号はライブラリのフットプリントと一致します。全経路の最短化や信号品質の実測を完了したという意味ではありません。

コネクタ・固定穴を固定し、部品を表側に載せる条件で検討しました。R6 の移動と経路変更も試しましたが、パッドや基板端との間隔不足などが生じたため採用しませんでした。この配線整理時点では全 81 部品の位置と向きが入力ファイルと同じでした。

採用した各変更はゾーン再計算後の DRC で未配線と新規指摘がないことを確認しました。J1 と J4 の参照名を修正した結果、DRC 指摘は 1 件減りました。残る 45 件はコートヤード重複 7 件、フットプリントライブラリ差異 26 件、シルク関連 12 件です。製造前にこれらの確認が必要です。

上表の DRC 数値は配線整理時点の結果です。`DRC.json` は現在の基板の結果、`DRC-before.json` は入力ファイルの結果です。`routing-changes.json` に配線整理時の区間別短縮量を記録しています。

## 電源選択ヘッダへの変更

上記の配線整理後、SW1 を表側の3ピンヘッダ J2 に交換し、D1 のカソードから J2 の3番への専用配線を追加しました。1–2短絡は J1 給電、2–3短絡は J1 で本体・ボタンLED、J4 でターンテーブル・センターバーを給電します。既存コネクタと固定穴の位置は維持しています。

現在の基板では J2 の位置が変更され、J60 は RESET HEADER（RUN–GND）、J61 は BOOTSEL HEADER（BOOTSEL_SW–GND）です。J3 の JST PH 2極・2.00mmピッチコネクターは1番が GND、2番が外部5V入力（EXT_5V）です。D1 の位置と周辺配線も変更されています。最新の DRC は未配線0件、指摘46件です。シルク印刷と銅箔・部品外形の重なりを含みます。回路図との比較指摘は67件で、J3・J60・J61 に関する不一致はありません。

## 最新の配線編集

GND のビア4本（座標 114.840,97.302・129.525,96.150・141.400,69.550・111.000,85.575 mm）を削除し、`/AE2_5V_IN` の裏面配線を引き直しました。ビアは112本から108本、配線区間は1110本から1112本になりました。配線総長は約2075.412 mmで変化していません。ゾーン再計算後も未配線0件、DRC指摘46件、回路図との比較指摘67件で、新規指摘はありません。
